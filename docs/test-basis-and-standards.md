# 테스트 기준과 적용 범위

목표는 게임 QA 신입이 검증 대상을 선정하고 근거를 설명하는 것이다. 공식 내부 요구사항은 보유하지 않으며, 실제 실행 화면·사용자가 확인한 조작·프로세스·이전 관찰을 테스트 베이시스로 사용한다. 관찰로 추론한 항목은 확정 제품 명세로 표현하지 않는다.

ISTQB의 테스트 조건, 기대결과, 상태 전이, 리스크 기반 선정 개념을 적용한다. 이 저장소의 모든 분류명이 공식 실라버스 항목이라는 주장은 하지 않는다.

| 기준 | 적용 |
| --- | --- |
| 진입 불가 위험 | Steam 환경·명령 호출·프로세스·초기 화면을 분리 |
| 입력/진행 위험 | 대상 창과 사전 화면 확인 후 시각 반응 관찰 |
| 정지 위험 | 프로세스 유지, 캡처, 연속 무변화 구간 기록 |
| 데이터 위험 | 저장 파일 후보의 경로 누락 관찰; 무결성은 별도 |
| 관찰 오류 위험 | 후보 판별, 필수 신호, 판단 보류를 명시 |

제안된 우선 지원 범위는 Windows의 기존 플레이 유저와 고정 창 크기이다. 실제 지원 환경은 [환경 프로필](environment-profile.md)을 채운 후 확정한다. 모든 해상도/유저 상태를 지원한다고 주장하지 않는다.

Steam 환경 snapshot은 기본 경로·프로세스 외 steam:// protocol 등록 명령도 읽는다. 등록 신호가 로그인·실제 실행 성공을 보장하지 않으며 해당 명령을 실행하는 검사도 아니다.

## 게임 없는 기준 실행

명령: `.\.venv\Scripts\python.exe -m pytest -q` (SHEEPY_RUN_STEAM_TESTS=0).
결과: **114 passed, 18 skipped**. 실제 게임 미실행 18개는 통과로 합산하지 않는다. 보관 이미지와 화면 준비 연결, 크기 변경 중단·예외 이벤트 보존 회귀가 통과했다.

단위 테스트는 관찰·판단 함수가 지정된 입력에서 동작하는지를 검증한다. 화면 인식 정확도와 실제 게임 반복 안정성이 검증됐다는 의미가 아니다. 이전 기준 실행 보관본은 artifacts/results/baseline-summary.json에 있다. artifacts/results/pytest-summary.json은 실행마다 갱신되므로 후속 실제 선택 실행 결과가 저장될 수 있다.

## 남은 필수 작업

1. [환경 프로필](environment-profile.md) 확인: 게임 버전, 해상도, 배율, 창 모드, 유저 상태.
2. 준비 가능한 로비에서 TC-019→010 검증, 각 입력 TC는 로비를 다시 준비해 개별 실행.
3. 같은 시작 조건에서 3회 결과와 실제 screenshot 대조.
4. [이미지 평가](image-validation.md)의 사람이 정답을 붙인 자료로 오탐/미탐/보류를 확인.

기존 게임 실행 결과는 [과거 이력](history/2026-09-13-before-revision.md)이며 이번 코드 수정 후 통과로 이월하지 않는다. 전체 완료 여부는 [완성도 판단](completion-review.md)을 따른다.

## 실제 기동 후속 확인

TC-001 환경과 TC-002 명령 호출은 실제 통과. TC-003은 최초 60초 미감지 후 Steam 준비 상태를 확인하고 한 번 재시도했다. 이전 자동 기동 관찰은 FAIL이며 수동 실행 후 TC-003 재관찰은 PASS이다. 최초부터 존재한 프로세스이므로 자동 기동 성공으로 합산하지 않는다. [실제 기동 기록](local-verification.md). 이후 화면·입력 진단을 추가했으며 최신 TC별 결과는 아래 재검증 문서를 따른다.

최종본 작업 범위와 단계별 완료 조건은 [최종본 계획](finalization-plan.md)을 따른다.

기동 진단 보완: 시간별 프로세스 관찰 8개 회귀 검증(최초 존재·마감 시각 감지·타임아웃·잘못된 시간값)이 통과했다. 실제 기동 재검증은 수동 실행 준비 대기이다.

입력 반응 평가 도구: 구현 및 인공 이미지 회귀 9개 통과. 빈 manifest 실행은 NOT_EVALUATED이며 실제 정답셋 검증은 미완료이다. [평가 절차](image-validation.md).

최신 실제 결과는 [2026-09-15 재검증](live-validation-2026-09-15.md)을 따른다. 크기 변경·이벤트 보존 수정 후 TC-010 정상 전환, TC-006 Space 시각 반응, TC-011 방향키 시각 반응이 각각 PASS 1회다. 입력 변화 차이는 각각 0.0259와 0.3485이며 점프·개별 방향 이동 성공 확정은 아니다. 동일 조건 3회 반복·짧은 안정성 최신 재검증·실제 오류 상황과 독립 이미지 평가는 남아 있다. 이전 보류와 통과 기록은 당시 근거로 보존한다.

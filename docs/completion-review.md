## 제출 기준

실제 게임에서 확인한 TC만 검증 완료로 표기한다. 나머지는 구현 또는 후보 단계로 둔다. 첫 제출은 기존 플레이 상태의 제한된 핵심 흐름을 반복 검증한 뒤 준비·입력·화면 근거를 공개하는 것을 권장한다.
현재는 판정 한계를 정직하게 보여주는 진행 중 프로젝트로 제시할 수 있다. 실제 화면을 확인하지 않고 100% 완료·프리즈 없음·점프 정상·세이브 무결성 보장이라고 표현하지 않는다.

최종본 작업 범위와 단계별 완료 조건은 [최종본 계획](finalization-plan.md)을 따른다.

최신 실제 게임 진단은 [2026-09-14 재검증](live-validation-2026-09-14.md)을 따른다. 플레이→언어 오탐 보관 표본은 수정 후 회귀 통과했지만 실제 게임 재검증·독립 정답셋 평가와 로비 항목 미탐 수정이 남아 최종본은 미완료이다.

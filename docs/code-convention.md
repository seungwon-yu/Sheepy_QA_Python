# Python QA 코드 기준

기존 공개 함수는 camelCase를 유지해 호출 호환성을 보존한다. pytest 함수는 snake_case, 클래스는 UpperCamelCase, 모듈은 snake_case이다. 스타일 일괄 변경보다 판정 의도가 읽히는 책임 분리를 우선한다.

관찰 함수는 사실을 반환하고, 판정 함수는 명시적 신호를 평가하며, local_checks는 실제 테스트 준비/증거를 연결한다. Windows 호출은 실제 실행 함수 안에 두어 Linux 단위 테스트에서 import할 수 있게 한다.

입력 직전에 대상 창을 확인하고 키 해제는 finally로 보장한다. 이미지 변화와 게임 동작을 같은 이름으로 표현하지 않는다. 순수 상태 준비 테스트는 관찰/시간/입력 함수를 주입해 실제 게임 없이 경계·중단을 검증한다. 단위 통과만으로 실제 이미지 정확도를 주장하지 않는다.

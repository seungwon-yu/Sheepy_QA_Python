# 플레이어 상태별 검증 전략

PLAYER-NEW/RETURNING/UNKNOWN은 실행 사전조건이다. Continue 후보가 보인다는 사실만으로 세이브 내용을 확정하지 않는다. 코드의 PLAYER_NEW 등 내부 표기는 같은 후보 개념이다.

우선 기존 플레이 데이터가 있는 환경을 대상으로 로비 후보·진입·시각 반응을 검증한다. TC-013은 별도로 준비된 최초 실행 상태에서만 평가한다. 현재 데이터가 RETURNING인데 NEW 기대값으로 실행해 제품 실패라고 보고하지 않는다.

| 상태 | 준비 | 실행 |
| --- | --- | --- |
| NEW | 별도 사용자 테스트 환경에서 사람이 확인 | TC-013 |
| RETURNING | 기존 Continue 진입을 사람이 확인 | TC-014/019/010 |
| UNKNOWN | 판단 근거 부족 | 후보 관찰 또는 보류 |

TC-015는 파일 존재 관찰이며 플레이어 진행 복원 검증은 아니다. 자동 세이브 삭제·백업 복구로 상태를 만들지 않는다. [환경 프로필](environment-profile.md)에 현재 상태를 기록한다.

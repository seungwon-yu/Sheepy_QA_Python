# 테스트 분류와 위험

| 분류 | 우선 이유 | TC |
| --- | --- | --- |
| 환경/실행 | 진입 불가의 원인 분리 | 001~003 |
| 화면/진입 | 다른 화면을 검증하는 오류 방지 | 004/005/009/010/018/019 |
| 입력 | 무반응/진행 불가 후보 | 006/011/016/017 |
| 안정성 | 종료·화면 정지 후보 | 007/012 |
| 유저 상태/저장 | 잘못된 사전조건과 데이터 해석 방지 | 013~015 |
| 도구 | 증거 저장과 판정 신뢰성 | 008 및 단위 테스트 |

소분류는 개별 TC의 관찰 목적이다. 게임 메커닉/그래픽 위험에서 시작하되 화면 변화 검사를 실제 메커닉 성공으로 확대하지 않는다. [추적표](traceability-matrix.md)

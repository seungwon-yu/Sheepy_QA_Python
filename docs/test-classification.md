# TC 대분류와 소분류 기준

## 목적

이 문서는 Sheepy 자동화 QA의 테스트 대분류와 소분류를 정의한다.

대분류는 ISTQB Foundation의 테스트 설계 흐름과 ISTQB Game Testing의 게임 특화 리스크를 함께 반영한다.

## 분류 기준

TC 대분류는 다음 기준으로 나눈다.

| 기준 | 설명 |
| --- | --- |
| 사용자 영향도 | 게임 실행, 진행, 조작에 직접 영향을 주는가 |
| 결함 발견 가능성 | 자동화로 결함 징후를 관찰할 수 있는가 |
| Evidence 명확성 | 실패 시 screenshot, process state, log로 근거를 남길 수 있는가 |
| 자동화 가능성 | Python 자동화로 반복 실행할 수 있는가 |
| 게임 QA 특화성 | 게임 메커닉, 그래픽, 레벨, 컨트롤러 특성과 연결되는가 |
| 플레이어 상태 영향 | 최초 실행 유저와 기존 플레이 유저의 기대결과가 달라지는가 |

## TC-GROUP-01 설치 및 실행 환경

목적: 테스트 대상 게임을 실행할 수 있는 기본 환경이 준비되어 있는지 확인한다.

ISTQB 기준:

- Foundation: 테스트 베이시스, 사전조건, 테스트 환경
- Game Testing: 플랫폼과 기술 리스크

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-01-A | Steam 환경 | Steam 클라이언트 실행 가능 여부 |
| TC-01-B | 게임 설치 | Sheepy 설치 또는 AppID 실행 가능 여부 |
| TC-01-C | OS/권한 | Windows 환경과 실행 권한 문제 |

## TC-GROUP-02 실행/종료

목적: 게임 프로세스가 정상적으로 시작되고 종료되는지 확인한다.

ISTQB 기준:

- Foundation: 기능 테스트, 기대결과
- Game Testing: 게임 제품 리스크, 크래시 리스크

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-02-A | 게임 실행 | Steam AppID 또는 실행 파일로 게임 시작 |
| TC-02-B | 프로세스 감지 | 지정 시간 안에 게임 프로세스 확인 |
| TC-02-C | 정상 종료 | 종료 입력 또는 프로세스 종료 확인 |

## TC-GROUP-03 메인 화면 및 초기 진입

목적: 게임 실행 후 초기 화면 또는 메인 화면에 도달하는지 확인한다.

ISTQB 기준:

- Foundation: 테스트 조건, 관찰 가능한 결과
- Game Testing: 그래픽, UI, 초기 플레이 진입

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-03-A | 초기 화면 도달 | 실행 후 빈 화면이 아닌 게임 화면 표시 |
| TC-03-B | 메뉴 표시 | 시작 또는 진행 가능한 UI 표시 |
| TC-03-C | 화면 캡처 | 초기 상태 screenshot evidence 저장 |

## TC-GROUP-04 입력 반응

목적: 키보드 입력이 게임에 반영되는지 확인한다.

ISTQB 기준:

- Foundation: 입력값과 기대결과
- Game Testing: Game Controllers Testing

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-04-A | 이동 입력 | 좌우 이동 입력 반응 |
| TC-04-B | 점프 입력 | 점프 입력 반응 |
| TC-04-C | 메뉴 입력 | Enter, Esc 같은 메뉴 입력 반응 |

## TC-GROUP-05 기본 플레이 흐름

목적: 사용자가 게임을 시작하고 첫 플레이 구간을 진행할 수 있는지 확인한다.

ISTQB 기준:

- Foundation: 시나리오 테스트, 상태 전이
- Game Testing: Game Mechanics Testing, Game Level Testing

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-05-A | 새 게임 시작 | 초기 화면에서 플레이 상태로 진입 |
| TC-05-B | 기본 이동 흐름 | 짧은 구간 이동과 점프 수행 |
| TC-05-C | 진행 가능성 | 첫 구간에서 조작 불능 또는 진행 불가가 없는지 확인 |

## TC-GROUP-06 화면/그래픽 표시

목적: 게임 화면이 정상적으로 표시되는지 확인한다.

ISTQB 기준:

- Foundation: 비기능 품질 특성 관찰
- Game Testing: Graphics Testing

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-06-A | 검은 화면 감지 | 실행 후 화면이 계속 검은 상태인지 확인 |
| TC-06-B | 화면 변화 | 입력 또는 시간 경과 후 화면 변화 확인 |
| TC-06-C | UI/텍스트 표시 | 주요 UI 또는 텍스트가 잘려 보이지 않는지 확인 |

## TC-GROUP-07 안정성/크래시/프리즈

목적: 게임이 일정 시간 동안 비정상 종료되거나 멈추지 않는지 확인한다.

ISTQB 기준:

- Foundation: 리스크 기반 테스트, 신뢰성
- Game Testing: 게임 제품 리스크, 기술 리스크

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-07-A | 크래시 감지 | 프로세스 비정상 종료 확인 |
| TC-07-B | 프리즈 감지 | 화면 변화가 장시간 멈추는지 확인 |
| TC-07-C | 짧은 안정성 | 일정 시간 동안 실행 유지 |

## TC-GROUP-08 Evidence 및 리포트

목적: 실패 시 판단 가능한 증거와 실행 기록이 저장되는지 확인한다.

ISTQB 기준:

- Foundation: 테스트 실행 결과 기록, 결함 보고
- Game Testing: 게임 결함 재현과 증거 확보

소분류:

| 소분류 ID | 소분류 | 설명 |
| --- | --- | --- |
| TC-08-A | Screenshot | 실패 또는 주요 단계 screenshot 저장 |
| TC-08-B | Process State | 프로세스 상태 저장 |
| TC-08-C | Test Result | PASS/FAIL/REVIEW_REQUIRED 결과 기록 |
| TC-08-D | Report | 사람이 읽기 좋은 요약 리포트 생성 |

## 후속 확장 대분류

| 대분류 | 확장 이유 |
| --- | --- |
| 사운드 | Game Testing의 Sound Testing 기준 반영 |
| 저장/로드 | 진행 상태 유지, 저장 파일, 재실행 흐름 확인 |
| 컨트롤러 | 키보드 이후 게임패드 입력 검증 |
| 로컬라이제이션 | 언어 설정, 텍스트 잘림, 번역 누락 확인 |

## 플레이어 상태 축

플레이어 상태는 별도 대분류로 두기보다 모든 TC에 붙을 수 있는 조건 축으로 관리한다.

상세 기준은 `docs/player-state-strategy.md`를 따른다.

| 상태 ID | 의미 | TC 영향 |
| --- | --- | --- |
| PLAYER-NEW | 최초 실행 유저 | 새 게임, 튜토리얼, 첫 진입 화면 기대결과에 영향 |
| PLAYER-RETURNING | 기존 플레이 유저 | Continue, 저장 상태 복구, 진행 상태 기대결과에 영향 |
| PLAYER-UNKNOWN | 상태 불명확 | 세이브 상태를 아직 자동화가 판별하지 못한 경우 |
